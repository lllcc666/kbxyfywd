# 妖怪背包模块

本文件总结妖怪背包列表的通用解析模式。

## 关键 opcode（AS3 常量名已核实）

- 查询 send：`1187329`（`OP_CLIENT_REQ_SPIRIT_LIST.send`）
- 列表 back：`1318401`（`OP_CLIENT_REQ_SPIRIT_LIST.back`）

## 常见解析目标

响应里通常要提取：

- 妖怪唯一 ID
- 配置 ID / 类型 ID
- 名称
- 等级 / 经验
- 系别
- 性格 / 资质
- 技能列表
- 装备灵玉

## 常见子结构

### 技能

关注：

- skill id
- 当前 PP
- 最大 PP
- 技能名

### 灵玉

关注：

- 位置
- 灵玉 ID
- 灵玉索引
- 名称

### 性格 / 资质

关注：

- 枚举值
- 展示名称
- 加成值

## 分析顺序

1. 确认查询包格式。
2. 找 `1318401` 的解析实现。
3. 对照 AS3 或抓包确认字段顺序。
4. 确认 UI 或自动化真正依赖的字段。
